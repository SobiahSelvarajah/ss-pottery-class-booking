# Pottery Class Booking App

A thoughtfully designed web platform showcasing independent pottery studios and enabling users to explore and book ceramic classes across London.

This project focuses on clean UX, scalable architecture, and modern frontend best practices, built as part of a portfolio case study.


## Tech Stack 

- Language: TypeScript
- Styling: Tailwind CSS v4
- Bundler: Turbopack
- Linting: ESLint
- Package Manager: npm


## Features

🏙 Studios directory with location-based filtering

🎠 Image carousels for each studio (manual, user-controlled)

📍 Location filter (Hackney, Greenwich, Islington, Peckham)

🎟 “Book studio” flow linking studios to class booking pages

🎨 Custom design system using a clay-inspired colour palette

📱 Fully responsive layout (mobile → desktop)

⚡ Built with Next.js App Router and Turbopack
